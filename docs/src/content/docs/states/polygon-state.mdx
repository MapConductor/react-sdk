# PolygonState

`PolygonState` holds a polygon's outer ring, optional interior holes, and styling as mutable, observable properties.

## Creating a PolygonState

```ts
createPolygonState({
  points: GeoPoint[];
  holes?: GeoPoint[][];    // interior rings
  id?: string | null;
  strokeColor?: string;    // default '#000000'
  strokeWidth?: number;    // default 2
  fillColor?: string;      // default 'transparent'
  geodesic?: boolean;      // default false
  zIndex?: number;         // default 0
  extra?: Serializable | null;
  onClick?: (event: { state: PolygonState; clicked: GeoPoint }) => void;
}): PolygonState
```

## Properties

| Property | Type | Notes |
| --- | --- | --- |
| `id` | `string` | readonly |
| `points` | `GeoPoint[]` | outer ring |
| `holes` | `GeoPoint[][]` | interior rings, stored as given. The `<Polygon>` component unions overlapping rings before rendering (see below). |
| `strokeColor`, `strokeWidth`, `fillColor` | `string` / `number` | |
| `geodesic` | `boolean` | |
| `zIndex` | `number` | |
| `extra` | `Serializable \| null` | |
| `onClick` | handler or `null` | |

## Holes are unioned at the component, not on the state

`createPolygonState()`, `copy()` and the `holes` setter store the rings exactly as you pass
them. Overlapping rings are merged by the `<Polygon>` component, which calls
`unionHolesInPlace(state)` once when there is more than one hole — the same place
Android does it (`PolygonComponent.kt`).

So if you render through `<Polygon>`, overlapping cutouts still merge automatically and
you don't need to pre-merge them. If you drive a controller directly, without the
component, call it yourself:

```ts
import { unionHolesInPlace } from '@mapconductor/js-sdk-core';

if (state.holes.length > 1) unionHolesInPlace(state);
```

:::note[Changed behavior]
The state used to union on construction, on `copy()` **and** in the `holes` setter, on top
of the component's own call — so a single `unionHolesInPlace()` could run the merge up to
four times, re-processing rings whose winding it had already flipped. The union now runs
exactly once, at the component.
:::

## Updating dynamically

```tsx
const [zone] = useState(() => createPolygonState({
  points: outerRing,
  fillColor: 'rgba(220, 38, 38, 0.2)',
  strokeColor: '#dc2626',
}));

useEffect(() => {
  zone.points = updatedOuterRing;
}, [zone, updatedOuterRing]);

return <Polygon state={zone} />;
```
